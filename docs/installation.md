# 설치·업데이트·데이터 이동

**Windows 사용자는 GitHub 시험판 IPA를 서명·설치하고, Mac 사용자는 Xcode로 직접 빌드·설치할 수 있습니다.** Mac에서 직접 빌드하려면 [README의 Mac 빠른 시작](../README.md#mac-install)과 [상세 빌드 안내](../ios-app/BUILDING.md)를 따라주세요.

아래 문서는 **Windows·Mac에서 이미 빌드된 IPA를 설치하는 경로**와 공통 데이터 이동 방법을 설명합니다. Mac에서도 IPA 설치를 선택할 수 있습니다. 설치 대상은 iPhone·iPad이며, Android에서 실행하려면 원본 SillyTavern의 Android 설치 방법을 사용하세요.

## 준비할 것

- iPhone 또는 iPad. 최소 OS 선언은 15.0이며 구형 OS 전체의 호환성을 검증한 것은 아닙니다.
- 최초 설치·서명에 사용할 Windows PC 또는 Mac과 Apple 계정
- 데이터 연결이 가능한 USB 케이블과 서명·설치 도구
- 대화에 사용할 원격 API 계정 또는 접근 가능한 개인 LLM 서버

PC는 설치·서명 갱신에 사용합니다. 설치 후 앱의 화면과 서버는 기기 안에서 실행되지만, 원격 API를 사용하려면 네트워크가 필요합니다. 별도 JIT 활성화 도구는 필요하지 않습니다.

## 1. IPA 받기

1. [GitHub Releases](https://github.com/p16481012/SillyTaevrn-ios/releases)를 엽니다. `Pre-release`는 시험판이라는 뜻입니다.
2. 해당 릴리스의 **Assets**에서 `SillyTavern-iOS-1.19.0-unsigned.ipa`를 받습니다. `Source code (zip)`은 설치 파일이 아닙니다.
3. 릴리스에 적힌 버전·빌드와 알려진 제한을 확인합니다. IPA는 다른 PC로 옮겨도 됩니다. Apple 서명·기기 연결은 설치할 PC에서 진행합니다.

원하면 함께 제공한 `SHA256SUMS.txt`와 다운로드 파일의 해시를 비교할 수 있습니다. 서명하기 **전**의 원본 IPA를 대상으로 합니다.

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\SillyTavern-iOS-1.19.0-unsigned.ipa
```

macOS 터미널:

```sh
shasum -a 256 SillyTavern-iOS-1.19.0-unsigned.ipa
```

해시는 다운로드한 릴리스에 첨부된 `SHA256SUMS.txt`의 값을 기준으로 합니다. 재서명하면 IPA 내용과 해시는 달라집니다.

## 2. Windows에서 서명·설치

Sideloadly를 사용하는 예시입니다. 도구의 화면·Windows 드라이버 요구사항이 바뀔 수 있으므로 [공식 다운로드와 FAQ](https://sideloadly.io/)를 함께 확인하세요.

1. 공식 사이트에서 Sideloadly를 설치합니다. 현재 공식 Windows 안내는 Microsoft Store판이 아닌 Apple 웹 배포판 iTunes·iCloud를 요구합니다. 기존 설치와 Apple 기기 드라이버 준비를 공식 안내에 맞춰 확인합니다.
2. 기기 잠금을 풀고 USB로 연결합니다. 기기에 **이 컴퓨터를 신뢰하겠습니까?**가 나타나면 신뢰합니다. Sideloadly의 기기 목록에 표시되는지 확인합니다.
3. IPA를 Sideloadly에 넣고 기기와 서명에 사용할 Apple 계정을 선택합니다. 서명·설치를 시작하고 필요한 인증을 완료합니다.
4. 설치 후 iOS에서 개발자 신뢰 확인을 요구하면 **설정 → 일반 → VPN 및 기기 관리**에서 해당 개발자를 신뢰합니다. 메뉴 이름은 OS 버전에 따라 다를 수 있습니다.
5. iOS 16 이상에서 개발자 모드를 요구하면 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시작·확인을 마칩니다.
6. SillyTavern을 실행합니다. 오류가 나면 앱을 삭제하기 전에 오류 문구와 서명 만료 여부부터 확인하세요.

무료 Apple 계정으로 서명한 앱은 일반적으로 **7일 후 갱신이 필요**합니다. 설치 시 사용한 도구의 갱신 방법을 유지하세요. 구체적인 계정별 한도와 갱신 조건은 [Sideloadly 공식 FAQ](https://sideloadly.io/)를 기준으로 합니다.

Mac에서도 Sideloadly를 사용할 수 있습니다. AltStore를 선호한다면 [AltStore Classic Windows 공식 안내](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)를 따라 설치한 뒤 IPA를 가져오세요. Mac에서 소스부터 직접 빌드하려면 [Xcode 빌드 안내](../ios-app/BUILDING.md)를 사용합니다.

무선 설치·갱신을 이용하려면 먼저 선택한 도구의 USB 페어링과 Wi-Fi 연결 설정을 완료하세요. 기기가 인식되지 않으면 [Apple의 연결 문제 안내](https://support.apple.com/ko-kr/108643)를 확인하세요.

## 3. 첫 실행과 API 연결

1. 첫 실행 안내에서 이름 등 필요한 초기 설정을 완료합니다.
2. 언어 설정에서 한국어를 선택하고 사용할 API 제공자·모델을 연결합니다.
3. 짧은 시험 메시지로 일반 응답, 스트리밍, 중지를 확인합니다.
4. 앱을 완전히 종료하고 다시 열어 같은 캐릭터·대화·설정이 유지되는지 확인합니다.

Ollama·KoboldAI 등 다른 기기의 서버를 사용할 때는 그 기기의 접속 주소를 입력합니다. `localhost`는 iPhone·iPad 자신을 가리킵니다. iOS가 로컬 네트워크 접근 권한을 요청하면 연결하려는 환경에 맞게 선택하세요. 권한을 거절했거나 서버 방화벽이 차단하면 해당 서버와 통신할 수 없습니다.

## 데이터 가져오기와 백업

캐릭터 카드, 설정집, 프리셋, 대화는 앱의 **각 기능에 있는 가져오기 메뉴**로 파일을 선택합니다. 대화 JSONL을 캐릭터 카드 가져오기에 넣는 식으로 서로 다른 종류를 섞지 마세요. 큰 파일은 현재 업로드 한도인 32 MiB를 확인하세요.

사용자 자료는 앱의 `Documents/SillyTavern`에 저장됩니다. 파일 앱의 **나의 iPhone/iPad → SillyTavern**에서 앱 문서 폴더를 열 수 있습니다. 실제 앱 문서 안에 사용자 데이터용 `SillyTavern` 하위 폴더가 있을 수 있습니다. 이는 자동 iCloud 동기화가 아닙니다.

| 목적 | 현재 방법 |
| --- | --- |
| 대화 이동 | 대화 내보내기 또는 자동 백업을 받은 뒤 해당 캐릭터의 대화 가져오기로 선택 |
| 카드·설정집·프리셋 이동 | 각 기능의 내보내기와 가져오기 사용 |
| 설정 되돌리기 | 앱의 설정 스냅샷 생성·복원 사용 |
| 사용자 자료 일괄 보관 | 전체 자료 ZIP 내보내기 후 앱 밖의 위치에 보관 |

**전체 ZIP의 원클릭 복원 기능은 없습니다.** 필요한 개별 파일을 ZIP에서 꺼내 해당 가져오기 메뉴를 사용하세요. 이 과정만으로 모든 앱 설정·폴더가 자동 복구되지는 않습니다. 파일 앱에서 사용자 폴더를 직접 교체하는 작업은 버전·경로·충돌을 확인해야 하므로 일반적인 업데이트 방법으로 권장하지 않습니다.

전체 ZIP 내보내기는 비밀 파일을 제외하므로 새 설치에서는 API 키를 다시 입력해야 할 수 있습니다. 반대로 사용자 폴더를 직접 복사한 백업에는 `secrets.json`과 개인 대화가 포함될 수 있습니다. [보안 안내](../SECURITY.md)를 확인하고 본인만 접근할 수 있는 곳에 보관하세요.

## 업데이트와 서명 갱신

1. 대화·카드·설정 등 필요한 자료를 앱 밖에 백업합니다.
2. 새 릴리스의 변경사항·빌드 번호와 데이터 이전 안내를 읽습니다.
3. 기존 설치와 같은 Apple 계정·서명 도구·앱 식별자 설정을 유지해 새 IPA를 서명하고 기존 앱 위에 설치합니다.
4. 앱을 실행해 기존 자료와 API 연결을 확인하고, 종료·재실행 후에도 유지되는지 확인합니다.

서명 팀이나 앱 식별자가 바뀌면 별도 앱으로 설치되거나 업데이트가 거부될 수 있습니다. **업데이트 문제를 해결하려고 기존 앱부터 삭제하지 마세요.** 앱 삭제 시 로컬 자료를 잃을 수 있습니다. 서명 만료 시에도 먼저 사용한 도구에서 갱신을 시도하세요.

## 문제가 생겼을 때

- 설치 실패·앱 실행 차단: 서명 유효기간, 개발자 신뢰, 개발자 모드와 설치 도구의 오류 확인
- 일반 채팅 실패: 제공자 연결, API 키·모델·할당량, 네트워크 확인
- 외부 확장만 실패: 해당 확장을 끄고 앱을 재실행해 비교, 정확한 확장 저장소·버전 기록
- 데이터·앱 문제: [진단 정보 내보내기](diagnostics.md)와 [오류 제보](https://github.com/p16481012/SillyTaevrn-ios/issues/new/choose) 이용

기기·OS, 앱 버전·빌드, IPA 출처, 설치 방법과 재현 순서를 적어주세요. API 키·개인 대화는 보내지 마세요.

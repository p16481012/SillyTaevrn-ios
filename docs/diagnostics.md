# 문제 해결과 진단 정보

## 먼저 확인할 것

| 증상 | 확인 사항 |
| --- | --- |
| 설치 실패·앱 실행 차단 | 서명 만료, 개발자 신뢰·개발자 모드, 설치 도구의 오류 문구 |
| 채팅 응답이 오지 않음 | API 키, 선택한 모델, 제공자 할당량, 네트워크 연결 |
| 특정 확장 사용 시 오류 | 해당 확장을 끄고 앱을 완전히 종료한 뒤 다시 실행 |
| 다른 기기의 로컬 서버에 연결 불가 | 서버의 실제 주소, iOS 로컬 네트워크 권한, 서버 방화벽 |

자료가 있는 앱을 삭제하기 전에 [백업·업데이트 안내](installation.md)를 확인하세요.

## 진단 정보 내보내기

1. 앱의 **사용자 설정 → 진단 로그 내보내기**를 선택합니다. 앱 시작 오류 화면에서도 같은 버튼을 사용할 수 있습니다.
2. iOS 공유 화면에서 **파일에 저장**을 선택합니다.
3. 저장한 `SillyTavern-diagnostics-날짜-시간.json`을 확인한 뒤 오류 제보에 첨부합니다.

진단 파일에는 앱·빌드·OS 버전, 기기 종류와 앱 시작 상태가 포함됩니다. 사용자 설정·캐릭터·대화·API 키 파일은 수집하지 않으며 원본 오류 문구나 콘솔 출력도 넣지 않습니다. 따라서 오류 화면에 별도 문구가 있다면 민감한 내용을 가린 뒤 함께 알려주세요.

## 오류 제보

[새 이슈 작성](https://github.com/p16481012/SillyTaevrn-ios/issues/new/choose)에서 다음 내용을 적어주세요.

- 기기와 iOS·iPadOS 버전
- 앱 버전·빌드, 다운로드 출처와 설치 방법
- 문제가 발생하는 순서, 기대한 결과와 실제 결과
- 확장과 관련된 경우 저장소 주소·버전, 확장을 끈 상태의 결과

API 키, 개인 대화, 사용자 폴더 전체는 공개 이슈에 올리지 마세요. 보안 취약점은 [보안 신고 안내](../SECURITY.md)를 따라주세요.

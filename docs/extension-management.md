# 확장 설치와 관리

확장 관리 화면에서 **HTTP/HTTPS Git 저장소 주소**로 확장을 설치할 수 있습니다. 별도의 Git 앱이나 JIT 활성화 도구는 필요하지 않습니다. SSH 주소는 지원하지 않습니다.

## 설치·업데이트

1. 사용하려는 확장의 안내에서 iOS에 없는 로컬 엔진·외부 실행 파일이 필요한지 확인합니다.
2. 확장 관리 화면의 설치 메뉴에 저장소 주소를 입력합니다.
3. 설치 후 화면 안내에 따라 새로고침하고 확장의 설정을 완료합니다.
4. 새 버전은 확장 관리 화면에서 업데이트합니다.

확장은 앱에서 실행되는 코드입니다. 신뢰할 수 있는 출처를 사용하세요. 설치가 가능하더라도 모든 확장의 모든 기능이 iOS에서 동작하는 것은 아닙니다. [앱의 기능 제한](../README.md#알아둘-점)을 함께 확인하세요.

## 브랜치 선택

브랜치 목록에서 사용할 버전을 선택합니다. 원격 브랜치는 `origin/브랜치명`으로 표시됩니다. 기존 로컬 브랜치를 선택하면 저장된 버전으로 전환하므로, 최신 변경사항을 받으려면 별도로 업데이트합니다.

전환 중에는 확장 크기에 비례하는 여유 공간과 네트워크 연결이 필요합니다. 파일 앱에서 같은 확장 폴더를 편집 중이라면 작업을 마친 뒤 전환하세요.

## 변경 충돌·업데이트 실패

직접 수정한 파일이나 충돌하는 이력이 있으면 업데이트·전환을 중단합니다. 수정 내용을 먼저 따로 보관하고 오류에 표시된 내용을 확인하세요. 임의로 덮어써서 변경사항을 없애지 않습니다.

`RECOVERY_REQUIRED`가 표시되면 설치 폴더와 오류에 표시된 복구 폴더를 모두 보관하세요. 곧바로 삭제·재설치하지 말고 [오류 제보](https://github.com/p16481012/SillyTaevrn-ios/issues/new/choose)에 확장 주소와 재현 방법을 알려주세요.

확장 사용 후 문제가 생겼다면 해당 확장을 끄고 앱을 재실행해 비교해 보세요. [문제 해결 안내](diagnostics.md)
